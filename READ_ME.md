# railway-sim prototype

Structure:
- data/kalyan_network.json: network config
- models/: Station, Track, Block, RailwayGraph
- utils/loader.py: load graph helper
- main.py: demo script

Run:
1. python -m venv venv
2. source venv/bin/activate   (windows: venv\Scripts\activate)
3. pip install -r requirements.txt
4. python main.py
